# Simon Says
This project is a web-based game inspired by Simon Says, where players follow sequences of colors to test memory and reaction skills.

## Launch
1. Install dependencies: `npm install` or `yarn install`
2. Start the development server: `npm start` or `yarn start`
3. Open http://localhost:3000 in your browser to play Simon Says
